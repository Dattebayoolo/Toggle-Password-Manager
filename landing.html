Toggle packs every feature of a premium password manager into a single open-source file. No subscription. No upsell.

AES-256-GCM Encryption
Every item in your vault is encrypted with AES-256-GCM — the same standard used by banks and governments. The key is derived with PBKDF2-SHA256 at 600,000 iterations, making brute-force attacks computationally infeasible.
Biometric Unlock
Authenticate with Windows Hello, Touch ID, or Face ID using the WebAuthn API. Your vault key is wrapped with your device's platform authenticator — no master password typing required on subsequent unlocks.
Google-style Security Checkup
A full security audit of your entire vault — detects weak passwords, reused credentials, and compromised entries via HIBP k-Anonymity (only the first 5 chars of a SHA-1 hash leave your device). Get a real-time health score with grade.

7 Vault Categories
Store more than just passwords. Toggle supports Logins, Passkeys, Credit Cards, Addresses, API Keys, Secure Notes, and a Trash with soft-delete restore — all in a unified, encrypted vault.
Google CSV Import
Migrate from Google Password Manager in seconds. Export your passwords from Chrome → Settings → Passwords, then drag-and-drop the .csv into Toggle. Full round-trip export back to Google format supported.
Dead simple

Up and running in 60 seconds.

No sign-up. No email verification. Just clone, run, and create your vault.

01
Clone & start
Run npm run dev in your terminal. The local server starts at 127.0.0.1:4242.
02
Create your vault
Choose a strong master password. Toggle derives a 256-bit AES key with 600,000 PBKDF2 rounds and saves an encrypted blob in IndexedDB — locally.
03
Add your passwords
Import from Google CSV in one click, or manually add logins, cards, passkeys, and notes. Every item is encrypted the moment you save.
04
Stay secure
Run the Security Checkup, enable biometric unlock, enable TOTP 2FA on accounts, and download your Emergency Recovery Kit as backup.
Built-in authenticator

2FA codes,
right in your vault.

Toggle's built-in TOTP engine (RFC 6238) generates live 6-digit codes with a real-time countdown. No separate authenticator app needed. Just paste your secret key or otpauth:// URI.

  • ✓ Accepts raw Base32 secrets or full otpauth://totp/ URIs
  • ✓ Live countdown circle with colour-coded urgency warning
  • ✓ One-tap copy from vault card chip or edit drawer
  • ✓ Secret stored encrypted, never in plaintext
